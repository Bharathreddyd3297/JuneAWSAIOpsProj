Telugu Pickles · Azure edition

From local Docker to AKS and AIOps

This project runs the Telugu Pickles shop locally, then deploys it to Azure Kubernetes Service with Terraform, GitHub Actions, Argo CD, and Argo Rollouts.

Application

React frontend, six Node.js services, and PostgreSQL.

Azure platform

AKS, Azure Container Registry, Azure Monitor, and managed identities.

Delivery

OIDC-authenticated GitHub workflows publish images; Argo CD syncs GitOps changes.

AIOps

Azure Functions analyzes AKS, Prometheus, and Log Analytics data with a configured Azure-hosted model.

1. Run the application locally

Install Docker Desktop, then start the project from projects/telugu-pickles:

docker compose up -d --build
./scripts/smoke-test.sh

The shop opens at http://localhost:3000. Use the local setup guide for detailed steps.

2. Provision Azure infrastructure

  1. Sign in with Azure CLI and choose the subscription.
  2. Copy projects/Infrastructure/bootstrap/terraform.tfvars.example to terraform.tfvars and enter your Azure region and GitHub repository.
  3. Run the bootstrap Terraform stack locally; it creates the state storage and GitHub OIDC identity.
  4. Set the OIDC, Terraform state, AKS SKU, and ACR GitHub repository variables listed in the AKS deployment guide.
  5. Dispatch the Azure Infrastructure workflow with plan, review it, then explicitly dispatch apply.

Infrastructure changes are not automatic. Review the Terraform plan and confirm the subscription, region, VM SKU, and budget before applying.

3. Bootstrap AKS and deploy the shop

Run scripts/bootstrap-aks.ps1 from PowerShell 7. It installs ingress-nginx, Argo CD, Argo Rollouts, Prometheus/Grafana, and creates fresh app secrets in Kubernetes. Then run App CI on main to build and push images to ACR. Argo CD deploys the updated GitOps manifests.

kubectl get ingress -n telugu-pickles
kubectl -n argocd get applications

4. Observe and release

Prometheus and Grafana provide metrics; Azure Monitor and Log Analytics collect cluster logs. The frontend uses blue-green delivery and catalog uses a Prometheus-checked canary. Use the rollout guide to inspect and promote releases.

5. Configure the AIOps assistant

Deploy a tool-calling model in Azure AI Foundry or an Azure OpenAI-compatible service, configure the endpoint and deployment in Terraform, and grant the Function identity access. The Python Function deploys through the AIOps Function GitHub workflow. See the AIOps setup guide.

Architecture

GitHub Actions --OIDC--> Azure
  |                         |-- Terraform --> AKS + ACR + Azure Monitor + Function
  |-- build/scan --> ACR    |-- AKS uses managed identity to pull images
  |-- image tag --> GitOps  |
                             Argo CD --> AKS workloads
                               |-- ingress-nginx --> Azure Load Balancer --> shop
                               |-- Prometheus/Grafana
                               |-- Azure Monitor Logs
                                          \--> AIOps Function + configured Azure model
