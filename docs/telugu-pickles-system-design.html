Trust boundaries

  • GitHub receives short-lived Azure tokens through federated OIDC; no cloud access keys are stored in GitHub.
  • AKS nodes pull images through the kubelet managed identity rather than a registry password.
  • The AIOps Function identity has read-only access to cluster resources and Log Analytics.
  • PostgreSQL/JWT credentials are generated by the AKS bootstrap script and stored as a Kubernetes Secret, not Git.
  • Argo CD and Grafana are not exposed publicly; operators use port-forwarding.

The Terraform stack and GitHub workflows are templates. Choose a region and VM SKU available in your subscription, configure the GitHub variables, review the plan, and explicitly approve provisioning. No Azure resource deployment has been run by this migration.
