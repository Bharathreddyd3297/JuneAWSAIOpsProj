Build

GitHub Actions uses Entra OIDC, scans eight images, and pushes commit-SHA tags to Azure Container Registry.

Deploy

Argo CD watches the Azure Kustomize overlay. Argo Rollouts performs frontend blue-green and catalog canary releases.

Observe

Prometheus and Grafana handle metrics. Azure Monitor Container Insights sends logs to Log Analytics.

Investigate

An AKS-hosted API uses Azure OpenAI and read-only specialists for logs, metrics, Kubernetes, and Argo status.

Identity and security

GitHub and the AIOps pod use federated identity instead of stored cloud credentials. The AIOps identity can query logs and inspect selected Kubernetes resources, but cannot mutate workloads, execute in pods, or read Secrets.

For exact resources, commands, and current deployment status, use the Azure service map and the Azure deployment guide.
